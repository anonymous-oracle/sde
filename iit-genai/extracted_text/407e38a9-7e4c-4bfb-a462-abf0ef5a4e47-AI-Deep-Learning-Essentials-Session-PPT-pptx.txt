                        Why Sparsity Breaks Similarity
The dot product between any two one-hot vectors is always zero
Cosine Similarity between one-hot vectors:

   cat        1    0    0    0    0    0    0     0      ·    kitten       0    0    0    0     1    0    0    0       = 0.00



  king        0    0    1    0    0    0    0     0      ·     queen       0    0    0    1     0    0    0    0       = 0.00

  💡 Insight
  One-hot vectors are orthogonal by construction — the model can never discover that "cat" and "kitten" are related.
  We need a representation where similar words are geometrically close.

        Backpropagation — How Neural Networks Learn

•   Forward Pass: Input flows through network → produces prediction ŷ
•   Loss Function: Measure error between ŷ and true label y
    •   MSE for regression: L = (1/n)Σ(yᵢ - ŷᵢ)²
    •   Cross-entropy for classification: L = −Σ yᵢ log(ŷᵢ)
•   Backward Pass: Compute gradient of loss w.r.t. each weight using chain
    rule
    •   ∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w (chain rule, layer by layer)
•   Gradient Descent Update: w ← w − η · ∂L/∂w (η = learning rate)
•   Variants: SGD (stochastic), Mini-batch GD, Adam, RMSProp — modern
    optimizers
•   Key challenges: Vanishing gradients (deep nets), overfitting, local
    minima

                                  Regularization — Penalise Complexity
What is Regularization?

Adds a penalty term to the loss function to discourage large weights. Forces
the model to stay simple and generalize better.


   L2 (Ridge)
   Loss + λ·Σw² Shrinks all weights smoothly toward zero.


   L1 (Lasso)
   Loss + λ·Σ|w| Drives some weights exactly to zero (feature selection).



 # Sklearn: Ridge (L2) & Lasso (L1)
 from sklearn.linear_model import Ridge, Lasso

 ridge = Ridge(alpha=1.0) # alpha = λ
 ridge.fit(X_train, y_train)

 lasso = Lasso(alpha=0.1)
 lasso.fit(X_train, y_train)
                              L1 vs L2 — Geometry & Sparsity

L1 — Lasso                                     L2 — Ridge
Constraint: diamond shape                      Constraint: circle shape




 •   Penalty: λ · Σ|wᵢ|                        •     Penalty: λ · Σwᵢ²
 •   Creates sparse models (weights → 0)       •     Shrinks all weights uniformly
 •   Good for feature selection                •     No exact zeros — keeps all features
 •   Non-differentiable at 0                   •     Differentiable everywhere
 •   Solver: coordinate descent                •     Has analytical closed-form solution




# L1 pushes weights to zero                   # L2 shrinks weights evenly
lasso = Lasso(alpha=0.5)                      ridge = Ridge(alpha=1.0)
print(lasso.coef_)                            print(ridge.coef_)
# → [0. 1.23 0. 0. 0.87]                      # → [0.12 0.88 0.03 0.21 0.75]

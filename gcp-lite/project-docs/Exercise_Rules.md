EXERCISE RULE (applies to every subject)
TWO KINDS OF TASK, NEVER MIXED
 PREDICTION  The learner reads a shown snippet or a described case and
             answers in words or numbers, with one reason. It is never
             run and never typed. Used for the concepts in between.
 EXERCISE    The learner writes the artefact (code, command, query,
             derivation or decision record) from a task described in
             words. No snippet to copy; syntax only as a pattern with
             blanks. The learner writes a one-line prediction first,
             then runs it and reports prediction + artefact + result.
WHEN     After a sub-topic of 3 to 5 concepts: ONE exercise.
         Never one per concept; never two for the same concept.
         Concepts in between get predictions only.
SIZE     Small: one file or one worked problem, one key idea the
         learner must discover by doing. Elaborate work is reserved
         for the top rung of a topic group.
GIVEN    Goal, files or interfaces, required behaviour, one edge case,
         what to predict first, what to report.
REVIEW   Line by line; name the one idea; confirm what is right,
         sharpen the mechanism. A miss gets one smaller, reworded
         retry of the same kind, not a new exercise.
FORM     Code for languages and tools; hand-worked problems for maths;
         commands for cloud; a one-line decision record for design.

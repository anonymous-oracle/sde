# B. Directives for this domain

## School-level foundations

**Placement note:** this part is remedial and taught on demand, not in sequence. It is opened only when the learner struggles with a basic skill while working in another part: a short diagnostic probe locates the gap, the matching topic area here is taught to the depth bar below, and the learner returns to where they were. A topic area the learner already handles fluently is never taught. Record each remedial session, and the topic area it covered, in the learner's record.

**Depth bar:** fast, error-free work on unseen multi-step problems in every group of this domain, with each rule justified rather than recalled. These are the roots every prerequisite chain ends in, so a gap here is closed before anything built on it.

**Capstone:** set only on the topic areas that were taught remedially: a timed mixed set across those areas, and a one-page explanation of a quantitative decision written for a non-expert.

# B. Directives for this domain

## Supplementary Applied Domains: Corporate Finance, Marketing, Learning Analytics & Game Engines

**Prerequisites:** arithmetic, algebra and exponential growth (part 01); probability, expectation and variance, correlation, hypothesis tests (part 03); decision theory (part 17); spreadsheets; for learning analytics, the applied ML basics in part 19; for game engines and rendering, vectors, matrices and transforms (part 03), memory and caches (part 02) and systems programming in Go or Rust (part 06 and the Rust track).

**Depth bar:** an introductory undergraduate or first-year MBA course in each area: every formula derived from its definition, then applied in a spreadsheet to a worked case with realistic numbers; for game engines, an undergraduate real-time rendering and engine-architecture course, every algorithm implemented in software before a GPU API is used.

**Capstone:** a business-case dossier: a project valued with NPV, IRR and a sensitivity analysis against a cost of capital estimated from CAPM and WACC; a go-to-market plan with segments, positioning, a channel mix and the metrics that judge it; and a learning-analytics pipeline over a public education dataset, from data and ethics through descriptive and predictive analysis; and, for game engines, a small engine with a software rasterizer, a fixed-timestep loop, collision and a frame-time budget measured against a prediction.

**Placement note:** these domains came from the NPTEL 2026 course list and have no natural home in the engineering parts. They are optional, taught on request and after the core engineering path, and connect back to cloud economics (part 16) and build-buy-rent decisions (part 17).

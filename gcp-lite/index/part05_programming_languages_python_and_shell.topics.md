### Python

- **Core language**
  - Variables, expressions and control flow: assignment binds a name to an object, so two names can refer to the same list; `x += 1` on an int binds x to a new object; operators follow a fixed precedence, and `and` and `or` short-circuit so the right side runs only when needed; the truth of a value is False for 0, empty containers, `None` and `False`, and True otherwise; `if`, `elif` and `else` choose one branch, `while` repeats while its condition holds, and `for` steps through any iterable
  - Functions, arguments and return values; recursion; a `def` statement binds a name to a function object, and a function that reaches no `return` returns `None`; recursion needs a base case that stops the calls and each call working on a smaller input, and CPython's default recursion limit of 1000 frames stops runaway recursion with a `RecursionError`, so deep recursion is often rewritten as a loop or with an explicit stack
  - Built-in data structures: list, dict, set, tuple; the dict as a hash table; a list is a dynamic array, so indexing is O(1) and appending is amortized O(1), while searching it for a value takes O(n); a dict and a set are hash tables with average O(1) lookup, insertion and deletion, and their keys must be hashable, so a list cannot be a key but a tuple of immutable values can; a tuple is an immutable sequence, and a dict keeps insertion order
  - Classes and object-oriented basics: a class is a callable that creates instances; `__init__` sets each instance's attributes, and methods take the instance as an explicit first parameter `self`; an attribute is looked up on the instance, then on its class, then on the base classes in method resolution order; inheritance reuses and overrides methods, and `super()` calls the parent's version; special methods such as `__repr__` and `__eq__` let objects work with `print` and `==`
  - Modules, packages and imports: a file of definitions runs its top-level code once, on first import, and is cached in `sys.modules`; a package is a directory of such files, marked by an `__init__.py` file (a directory without one can still be imported as a namespace package); `import x` binds the name x, `from x import y` binds y, and relative imports such as `from . import y` work only inside a package; `if __name__ == "__main__":` runs code only when the file is executed rather than imported
  - Exceptions, `try`/`finally`, context managers; reading a traceback; `except` clauses are tried in order and match by exception class, and a bare `except:` also catches interrupts and exits, so name the class; the `else` block runs only when no exception was raised, and `finally` runs on every exit path; a context manager's `__enter__` and `__exit__`, or a `@contextlib.contextmanager` generator, guarantee cleanup such as closing a file; a traceback lists the calls from outermost to innermost, and its last line gives the exception class and message, so read it from the bottom up
  - Strings: slicing, immutability and the common string methods; formatted output with f-strings and format specifications; `range()`, `break`, loop `else`, `pass`, `del` and `None`
  - Parameters: default, keyword-only and variadic (`*args`, `**kwargs`); scope by the LEGB rule with `global` and `nonlocal`; nested functions and closures
  - Comprehensions (list, dict, set) and generator expressions; `lambda`; higher-order functions (`map`, `filter`, `sorted(key=)`); functions passed as arguments and returned; iterators and generators; `itertools`
  - Functional style: pure functions, immutability, `functools` (`reduce`, `partial`, `lru_cache`); contrast with C's manual memory management (`malloc`/`free`)
  - Standard input and output; text and binary files with `open` and `with`; `pathlib`; reading a text file line by line by iterating the file object, so memory stays bounded; the read modes `'r'`, `'rb'`, `'w'` and `'a'` and what each does to an existing file (`'w'` truncates it, `'a'` appends); explicit `encoding='utf-8'` on text files, and the newline translation that text mode performs
- **Environment and tooling**
  - Virtual environments; package management with pip; lock files for reproducibility
  - A hand-built test runner that discovers `test_` functions, then pytest (fixtures, parametrisation, assert rewriting)
  - Editor setup and extensions: VS Code with its language extensions; a debugger run configuration per project; formatter and linter run on save and in CI; text editing as a skill: multi-file search and replace, a language server that supplies diagnostics, go-to-definition and rename, and running in the integrated terminal the same test command that CI runs; for Go, the official Go extension with `gopls` as the language server, with `gofmt` and `go vet` run on save
  - Print-debugging: printing the state at a suspected fault point, labelled and removed afterwards; what a print shows that stepping and breakpoints do not, and when it is the faster tool
  - Notebooks and scripts: a Jupyter notebook is an ordered list of cells whose outputs are saved in the file, so cells run out of order leave hidden state that a fresh run does not reproduce; restart the kernel and run all cells before trusting a result; move reused logic into an importable module, keeping the notebook for exploration, and run that logic as a script from the command line with a checked exit code
- **Python runtime model**
  - Call by sharing; names as references to heap objects; reference counting plus a cycle collector
  - The global interpreter lock and the free-threaded build; `asyncio` as cooperative concurrency
  - Arbitrary-precision `int`; floor division and modulo with negative operands; an `int` grows to hold any size, so arithmetic never wraps, but big numbers cost more per operation; `//` rounds toward negative infinity, so `-7 // 2` is `-4` and `-7 % 2` is `1`, and `a == (a // b) * b + a % b` holds for every nonzero `b`; C truncates toward zero instead, giving `-3` and `-1`, so the same expression differs across languages
  - `str` as code points versus `bytes`; `decimal.Decimal` for money; a `str` is a sequence of Unicode code points, while `bytes` is a sequence of integers from 0 to 255, and `.encode('utf-8')` and `.decode('utf-8')` convert between them, with `UnicodeDecodeError` raised on invalid input; `Decimal` stores a decimal value exactly, so `Decimal('0.1') + Decimal('0.2')` is `Decimal('0.3')` while floats give `0.30000000000000004`; build a Decimal from a string, since `Decimal(0.1)` copies the inexact binary float; the context sets the precision and rounding mode
  - Late-binding closures and the mutable-default-argument trap: a closure looks up its free variables when it is called, not when it is defined, so closures created in a loop all see the final value of the loop variable unless it is passed in as a default argument or through a factory function; a default value is evaluated once, when the `def` runs, so `def f(x, acc=[])` shares one list across all calls, and the fix is `acc=None` with `if acc is None: acc = []` in the body
- **Python for data and services**
  - NumPy: n-dimensional arrays, dtypes and shapes; indexing, slicing and boolean masks; broadcasting; vectorized operations instead of loops; linear-algebra and random routines; strides and views, where a slice shares memory with its base array while .copy() and fancy indexing make a new array; seeded generators with numpy.random.default_rng(seed) for reproducible draws; numpy.linalg.solve for Ax = b, inv, det, eig for eigenvalues and eigenvectors, and norm; axis reasoning, where a reduction over axis k removes that axis from the shape and `keepdims=True` keeps it as length 1; dtype reasoning, where fixed-width integers wrap silently on overflow and mixing integer and float arrays promotes the result to float
  - pandas: DataFrames, selection, grouping, joins, missing values; the index as the row label that aligns data across operations; groupby as split-apply-combine; merge with its inner, left and outer joins and the row count each produces; NaN for missing floats, with the nullable dtypes for missing integers and strings
  - Matplotlib: line, scatter and histogram plots; Jupyter notebooks; subplots and GridSpec layouts, contour and heatmap plots, and savefig to write a figure to a file; 3D surface and scatter plots through `projection='3d'` on the axes, and savefig with `dpi` and `bbox_inches='tight'` so that labels are not clipped
  - SciPy: `scipy.optimize` for minimization and root finding; `scipy.stats` distributions and hypothesis tests; `scipy.signal` filters and spectra; each result checked against a hand-built version; `scipy.signal.butter` designs a Butterworth filter returned as second-order sections, `filtfilt` applies it forward and backward for zero phase, and `welch` estimates a power spectral density by averaging windowed periodograms, whose frequency resolution is the sampling rate divided by the segment length
  - Seaborn: distribution, categorical and regression plots drawn on Matplotlib axes; figure-level versus axes-level functions; long-form data frames; bootstrapped confidence intervals
  - Plotly: interactive figures rendered in the browser with hover, zoom and linked selections; a dashboard served from Python callbacks; dashboards as operations tools, with panels for latency, traffic, errors and saturation, each answering one question, and every alert linked to a runbook that names its trigger, the first checks with their exact commands, the mitigation and the rollback, and who to escalate to
  - FastAPI: async endpoints, Pydantic request and response models, dependency injection, streaming responses, served by Uvicorn
  - LangChain, LlamaIndex, vLLM and Ray, taught as service concepts rather than reimplemented: LangChain composes prompt templates, model calls, output parsers and tool calls into chains; LlamaIndex builds a retrieval pipeline that splits documents into nodes, embeds them, retrieves the top-k by similarity and passes them to a response synthesizer; vLLM serves LLMs with a paged KV cache that allocates attention state in fixed-size blocks and batches requests continuously; Ray runs tasks and actors across a cluster, passing large objects by reference through its object store

### Shell and working with APIs from code

- **Bash scripting**
  - Variables, quoting, loops and conditionals: single quotes take text literally, double quotes allow `$var` and `$(command)` expansion, and an unquoted expansion splits on spaces and expands globs, so "$file" in double quotes is the safe form; `for` loops over a list of words or over lines of command output, and `while read -r line` reads one line at a time; `if [[ -f "$path" ]]` tests a condition, and a command's exit status 0 means true
  - Pipes, redirection and exit codes; `set -euo pipefail`; a pipeline's exit status is that of its last command unless `pipefail` is set, which makes it the last nonzero status; `set -e` stops the script at the first failing command, except inside an `if` test or before `||`, and `set -u` makes an unset variable an error; `2>&1` sends stderr to wherever stdout goes, and `$?` holds the last exit code, where 0 means success
  - Scripts as glue for CI/CD and automation; a Python script with an `if __name__ == "__main__"` entry point, arguments read by argparse, and subprocess.run calls whose exit codes are checked
  - `jq` for filtering and reshaping JSON on the command line: `jq` reads JSON on standard input and writes results to standard output; `jq '.items[] | {name, id}'` iterates an array and builds a new object for each element, `select(.status == "ok")` keeps matching elements, and `-r` prints strings without their JSON quotes; a common mistake is forgetting that `.items[]` yields many values, so the output is not one array unless it is wrapped in brackets
- **Calling APIs from code**
  - HTTP clients and JSON parsing: a request has a method, a URL, headers and an optional body, and a response has a status code (2xx success, 4xx client error, 5xx server error) and a body; `requests` or `httpx` send these from Python, `response.json()` or `json.loads` turns the body into dicts and lists, and every call sets a timeout so that a hung server cannot block the program forever; `response.raise_for_status()` raises an exception for 4xx and 5xx codes
  - Cloud SDKs (google-cloud-*, boto3, the Azure SDK): each SDK wraps one provider's API in client objects, and each finds credentials through a standard chain (Application Default Credentials for Google Cloud, the boto3 credential chain for AWS, `DefaultAzureCredential` for Azure), so no key is written in source; the clients handle retries and paginate long list results; a client is created once and reused, since creating one per request repeats setup work; the SDK call and the matching `gcloud`, `aws` or `az` command act on the same resource
  - RPC and REST calls from Python and from curl: `curl -sS -X POST -H 'Content-Type: application/json' -d '{"id": 1}' URL` sends a JSON body, `-i` prints the status line and headers, and `-f` makes an HTTP error code a nonzero exit; REST names resources by URL and uses the HTTP method as the verb, while RPC names a procedure and passes typed arguments, as gRPC does through generated client stubs in Python
  - DB-API parameter binding; `psql` against a local Postgres in Docker; file encodings when loading data

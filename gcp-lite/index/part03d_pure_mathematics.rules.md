# B. Directives for this domain

## Pure Mathematics: Algebra, Topology, Geometry, Logic & Rigorous Analysis

**Prerequisites:** Part 03 (proof techniques, linear algebra, discrete mathematics) and Part 03b (real analysis, calculus, complex and functional analysis basics); Part 08 for graph algorithms when doing the pure combinatorics and graph theory group.

**Depth bar:** Graduate depth: state and prove the central theorems of each area, compute the standard examples by hand, and explain where each result is used in computer science, machine learning or signal processing.

**Capstone:** A proof portfolio of one fully written proof per group, plus a from-scratch computational toolkit (permutation groups with Sylow subgroups found for small orders, the simplicial homology of a small complex by Smith normal form, a finite-field GF(pⁿ) arithmetic library) with each result checked against hand computation.
